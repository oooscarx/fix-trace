# TUI 与 Desktop 快捷键

## TUI

| 按键 | 行为 |
|---|---|
| `Enter` | 发送；Approval 中执行当前单键决定 |
| `Alt+Enter` / `Ctrl+J` | Composer 换行 |
| `Ctrl+P` | 命令面板 |
| `Ctrl+O` | Session Picker |
| `Ctrl+B` / `Ctrl+I` | 显示/隐藏 Sidebar 或 Inspector |
| `Tab` / `Shift+Tab` | 补全引用，或切换 Inspector |
| `PageUp` / `PageDown`、`g` / `G` | 浏览 timeline |
| `Ctrl+X` | 安全退出全屏并用 `$VISUAL`/`$EDITOR` 编辑长 Prompt |
| `Ctrl+C` | 第一次取消 Task；1.5 秒内第二次退出 |
| `?` | 帮助 |

Approval modal 中：`y` 仅本次、`t` 当前 Task、`s` 当前 Session 内结构化等价项、`n` 拒绝、`c` 取消 Task。

## Desktop

| 按键 | 行为 |
|---|---|
| `⌘/Ctrl+K` | 搜索 Session |
| `⌘/Ctrl+Shift+N` | 新建 Session |
| `⌘/Ctrl+1…8` | 切换 Inspector tab |
| `Enter` | 发送 Composer |
| `Shift+Enter` | Composer 换行 |
| `Escape` | 关闭 Session 操作弹窗 |

完整交互见 [TUI](tui.md) 和 [Desktop](desktop.md)。
